# A11y Compose

Два экрана на Jetpack Compose, на которых доступность встроена в обычный интерфейс: каталог приёмов и форма записи на приём.

Демонстрация прохода с TalkBack: [docs/a11y-demo.mp4](docs/a11y-demo.mp4).

Динамические цвета отключены, чтобы контраст не зависел от обоев. Текст задан в `sp`, цели нажатия не ниже 48 dp, экраны прокручиваются при крупном шрифте.

## Экраны

**Каталог приёмов.** Заголовки для перехода TalkBack, подпись у кнопки без текста, декоративная иллюстрация без описания. Карточка читается одним элементом и сообщает состояние «Изучено». Список объявляет позицию элемента.

**Форма записи.** Подписи у полей, ошибка текстом с переносом фокуса, живое объявление результата. Переключатель, слайдер и радиогруппа читаются вместе с подписью. В блоке «Итог визита» цена нарисована слева, а TalkBack сначала читает услугу. Кнопка отправки недоступна без согласия, причина написана рядом.

## Запуск

Откройте проект в Android Studio и запустите конфигурацию `app`. Нужны уже установленные JDK, Android SDK и платформа `android-36.1`. `minSdk` — 26, `targetSdk` — 36.

## Проверка

Включите TalkBack и в его настройках пункт «Показывать речевой вывод»: фраза дублируется текстом внизу экрана.

На эмуляторе отправьте сочетания клавиш в виртуальное устройство (`⋮ → Settings → General → Send keyboard shortcuts to → Virtual device`) и выберите в TalkBack схему **Default keymap**. Дальше:

- `Alt + вправо` / `Alt + влево` — соседний элемент
- `Alt + Enter` — активировать

Приложение в порядке, если по пути появляются такие фразы:

1. «Показать подсказку по проверке», после нажатия — текст подсказки.
2. Карточка «Заголовки» целиком за один шаг, со словами «Не изучено», затем «Изучено».
3. «Заполненность анкеты, заполнено 0 из 3».
4. Поле «Имя»; `Enter` переносит фокус на «Эл. почта».
5. Сначала «Терапевт», потом «1 500 ₽».
6. «Отправить запись» недоступна, пока нет согласия.
7. Пустая отправка: «Ошибка: введите имя», рамка на поле «Имя».
8. Имя и почта `name@example.com`: «Готово: запись для … отправлена».

Отдельно, уже без TalkBack: максимальный размер шрифта и тёмная тема. Текст не обрезается, кнопки остаются читаемыми.
